# shidoku-ia-program
# Shidoku IA Program

This Python program reproduces the computational results used in my IB Mathematics AA HL Internal Assessment on minimum-clue Shidoku puzzles.

## How to run

1. Download `shidoku_ia_program.py`
2. Make sure Python 3 is installed
3. Run:

python3 shidoku_ia_program.py

No additional libraries are required.

## Main results

The program reproduces:

- 288 completed Shidoku boards
- 96 Type 1 boards
- 192 Type 2 boards
- 128 position symmetries
- 3,072 full Shidoku symmetries
- 12 Type 1 minimum puzzles
- 128 Type 2 minimum puzzles
- 25,728 uniquely solvable four-clue puzzles
- 13 equivalence classes
